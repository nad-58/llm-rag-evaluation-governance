# Release notes — v0.1.0

## LLM RAG Evaluation Governance

Initial public release of the lightweight LLM/RAG evaluation and governance toolkit.

### Included

- Groundedness scoring and acceptance decisions
- Retrieval recall and top-k relevance checks
- Unsupported-claim and hallucination-risk evaluation
- Human-review escalation logic
- Synthetic runnable examples
- Unit tests for metrics, risk, and review logic
- Package metadata and editable installation
- CI compilation, tests, examples, and dependency auditing
- Dependabot for Python packages and GitHub Actions
- Governance documentation and reusable templates

```text
v0.1.0 — Initial LLM/RAG Evaluation Toolkit
```
