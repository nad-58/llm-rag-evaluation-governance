# Contributing

Contributions to examples, tests, templates, and documentation are welcome.

## Setup

```bash
python -m venv .venv
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

## Guidelines

- Keep changes focused.
- Add tests or runnable examples for new behaviour.
- Use type hints and docstrings in reusable modules.
- Document assumptions, thresholds, and limitations.
- Use original, synthetic, or publicly shareable content.

## Commit prefixes

Use `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, or `chore:`.

## Pull requests

Describe the purpose, files changed, validation completed, and known limitations.
